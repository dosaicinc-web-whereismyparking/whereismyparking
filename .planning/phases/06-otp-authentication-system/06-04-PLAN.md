# Plan 06-04: Auto-logout on 30-day Token Expiry

Ensure that user sessions are automatically invalidated after 30 days and the middleware enforces this across protected routes.

## Success Criteria

- [ ] JWT tokens are issued with a 30-day lifetime (if configurable via API) or middleware checks `iat` (issued at) time
- [ ] Middleware redirects to `/login` if session is older than 30 days or invalid
