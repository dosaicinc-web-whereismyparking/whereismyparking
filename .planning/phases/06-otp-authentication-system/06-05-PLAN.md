# Plan 06-05: Admin Mobile Whitelist Enforcement

Restrict administrative access to a predefined list of mobile numbers specified in the environment configuration.

## Success Criteria

- [ ] `ADMIN_WHITELIST_MOBILES` env variable is used to filter admin login attempts
- [ ] Non-whitelisted numbers are blocked from receiving OTP if target role is admin
- [ ] Whitelisted numbers are assigned the 'admin' role in the DB or session metadata on successful login
