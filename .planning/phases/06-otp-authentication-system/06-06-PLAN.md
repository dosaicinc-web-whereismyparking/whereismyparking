## Success Criteria

- [ ] OTP send → receive SMS → verify → JWT issued
- [ ] Wrong OTP 3 times → lockout confirmed
- [ ] Resend within 60s → blocked with countdown
- [ ] Non-whitelisted mobile on admin → blocked
