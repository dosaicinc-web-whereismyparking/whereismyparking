# Plan 06-01: Fast2SMS Integration and OTP Send

Integrate Fast2SMS API to send OTP via SMS and store session state in `otp_sessions` table.

## User Review Required

> [!IMPORTANT]
> This plan requires a `FAST2SMS_API_KEY` in `.env.local`. Ensure you have one from the Fast2SMS dashboard (Dev API section).

- **SMS Provider:** Fast2SMS (Direct OTP Route)
- **Database:** New `otp_sessions` table for state tracking

- [ ] `supabase/migrations/05_otp_sessions.sql` created
- [ ] `src/lib/sms.ts` implements `sendSMS(phone, otp)`
- [ ] `POST /api/auth/send-otp` generates 6-digit OTP and calls Fast2SMS
- [ ] OTP hash is stored in `otp_sessions` with 5-minute expiry
