| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | OTP login | mitigate | Phone number validation with Indian format regex, OTP expiry check |
| T-01-02 | Tampering | Session tokens | mitigate | JWT HS256 signing, httpOnly cookies, short 15-min expiry |
| T-01-03 | Repudiation | Admin actions | mitigate | Supabase audit logs, session tracking |
| T-01-04 | Information Disclosure | User sessions | mitigate | No PII storage for anonymous users, encrypted tokens |
| T-01-05 | Denial of Service | OTP spam | mitigate | Rate limiting (60s cooldown), attempt counting |
| T-01-06 | Elevation of Privilege | Admin access | mitigate | Database whitelist check before session creation |
</threat_model>
